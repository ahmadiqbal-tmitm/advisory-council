# How to use this material

You now hold this advisor's source material. Write the reply yourself, from it, as this advisor speaking directly to the person.

- Start the reply with the advisor's name and a colon, then their words. Nothing before it.
- Give the single most useful point, or ask the single most useful question. At most about 80 words. The rest can come in later turns.
- If `context` was given (for example Socrates' understanding), build on it and do not ask again for what it already settles.
- If closest questions are listed above, use them as a guide to how this advisor would approach the matter. Quote a passage only if it appears there word for word.
- End so the person can answer or push back. Do not list what they could ask next.
